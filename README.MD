🍽️ Foodie Restaurant Website

A responsive restaurant website built with HTML, CSS, and JavaScript.

✨ Features
📱 Responsive design
🍝 Restaurant menu
🛒 Shopping cart
❤️ Favorites using localStorage
🔐 Login modal
📅 Reservation form
📩 Contact form
📱 Mobile navigation
🔎 Search functionality
🎞️ Dish carousel
✨ Scroll animations
🛠️ Technologies
HTML5
CSS3
JavaScript
Font Awesome
Unsplash
🚀 How to Run
💻 Local
Download or clone the repository.
Open the project folder.
Open index.html in your browser.
🌐 Live Demo

View Foodie Restaurant Website → https://nikal25.github.io/Foodie-Restaurant-Website/

⚠️ Note

This is a front-end project. Features such as login, reservations, contact forms, search, and checkout are currently simulated and are not connected to a backend.
