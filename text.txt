Это одностраничный сайт ресторана Foodie, разработанный на чистом HTML, CSS и JavaScript, без фреймворков.

Основные особенности проекта:

адаптивная верстка для мобильных и десктопных устройств;
интерактивное меню с добавлением блюд в корзину;
корзина автоматически считает количество товаров и общую стоимость;
система избранного реализована через localStorage, поэтому данные сохраняются после перезагрузки страницы;
модальные окна для авторизации, бронирования столика и обратной связи;
мобильное навигационное меню;
плавная прокрутка по секциям;
карусель популярных блюд;
анимации появления элементов через IntersectionObserver;
изменение стиля header при прокрутке;
базовая поддержка клавиши Escape для закрытия модальных окон и корзины.

При этом проект является frontend-версией: авторизация, бронирование, отправка сообщений, поиск и checkout пока работают как демонстрация и не подключены к backend или базе данных.
